# Siming 3.1.13 测试版

本地测试候选包，暂不上传发布。

## 对话、立项与作品上下文

- 顶部上下文选择器同时列出正式作品和未完成/已完成立项数据。
- 多个对话可以绑定并共同维护同一份立项数据；新建对话不会擅自复制或清空当前上下文。
- 返回旧对话时恢复该对话绑定的立项数据，并丢弃旧请求延迟返回的跨会话结果。
- 清空上下文后发送第一条消息会自动新建立项数据；在旧上下文明确要求创建新小说时也会创建全新立项。
- 正式作品会反查其来源立项数据，项目助手可读取并调用立项工具继续修改。
- 最终审阅确认后确定性创建小说项目，并直接打开已创建的项目。

## 对话式增量维护

- 立项助手每轮先读取现有 session、artifact 和 entity，再依据数据缺口提问。
- 用户回答或补充事实后，助手先增量写入能确定的结构化内容，再提出下一项最有价值的问题。
- 世界观、角色、地点、势力、分卷、章节与场景细纲可以按任意顺序持续补充。

## 编辑器体验

- 完整编辑器采用更清晰的稿纸式信息层级、双栏字段布局与自动保存状态提示。
- 编辑器展开时扩大数据区并收窄聊天区，保留明确的“返回立项数据”入口。
- 立项卡片使用明确的“进入编辑器”按钮，未生成的数据也可直接编辑；编辑器中的结构化分组默认全部展开。

## 本地模型与导航

- 模型存储目录可调用系统文件夹选择器，自有 GGUF 可调用系统文件选择器。
- 中断的模型下载可从已保存的部分文件继续，页面同时提供“继续下载”入口。
- 本地模型成功加载后自动通过本地运行验证，可直接设为默认模型。
- 从任务中心跳转到独立模型中心后仍显示全局导航，不再进入无法返回的页面。
- 立项代理不再把只读或失败工具调用误报为“已保存”；成功写入后立即刷新右侧数据，并基于真实工具结果总结和追问。
- “立项数据”和“正式作品”在助手中统一为“作品上下文/作品资料”，旧草稿异常不会清空整个作品选择列表。
- API 与本地模型的连接测试、运行验证和测速兼容思考输出；司命本地 AI 的首次验证不再被自身的未验证状态拦截。

## 本地验证

- 后端立项、对话历史、项目助手针对性测试：54 项通过，7 项按环境跳过。
- 前端对话式立项针对性测试：12 项通过；6 项旧采访流程测试标记为退役。
- 前端生产构建通过。
