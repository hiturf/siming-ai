# 司命 3.3.2

3.3.2 修复桌面端启动超时，并合并 Android TXT 导入及本机 CLI 项目助手可靠性改进。

## 修复

- 将 `character_ai_config` 补入桌面端、Gateway 与 Android 共用的同步实体契约。
- 增加捕获实体与公开同步协议的一致性回归测试，防止后续新增实体时再次遗漏。
- Gateway 同步队列恢复改为非阻塞；单条过期或异常任务会记录日志并保留重试，不再阻止整个桌面应用启动。
- Android TXT 导入支持 UTF-8、UTF-16、GB18030 与 Big5 自动识别，并将在线批量建项压缩为一次原子导入。
- 优化手机端长篇 TXT 拆章、离线入库与同步调度，避免主线程卡顿和数百次串行请求。
- 立项对话统一解析并向生成任务传递实际模型，避免默认模型可对话却无法生成结构化内容。
- 为不支持原生工具调用的本机 CLI 增加受控 JSON 工具桥；读取可执行，写入必须获得一次性授权并由后端校验。
