# Siming v3.1.0

3.1.0 聚焦“从设定到正文”的可靠闭环，并继续保持软件免费、开源和本地优先。

## 重点更新

- 章节序号、标题别名和“下一章”等表达由项目 Agent 结合真实作品实体理解并取得 ID；界面当前选中项不再替用户决定目标。
- 写章请求只有在模型主动取得真实章级节点并调用写作工具后才会生成独立未保存草稿；系统不再使用正则或确定性写章 fallback。
- 作品助手任务与页面连接解耦，支持停止、断流恢复和重启后的中断状态；同一大纲并发或重试不会生成重复、空白章节。
- 创建新作品新增“按我的设定立项”“帮我探索创意”“导入已有小说”三个入口；作者设定、已有大纲和不可改动项会贯穿立项流程。
- 每个立项阶段可输入要求让 AI 定向调整，失败时保留当前草稿，不再只能反复随机生成。
- 修复 Windows“减少动画”开启时 Ant Design 下拉框可能被定位到视口外的问题。
- 写作工作台可直接切换已验证可用的全局默认模型；章节编辑区增加可见的“删除本章”。

## 兼容性与数据

- 旧 V2 立项草稿会以探索模式继续读取，已有项目和章节不会被自动合并或删除。
- Android 应用版本同步为 3.1.0；本版新增桌面工作台能力不移植到手机端，Gateway 同步协议保持不变。
- 不增加遥测，不静默切换付费模型，API Key 与项目数据仍由用户设备保存。

## 下载校验

请仅从本仓库的 GitHub Release 下载 `Siming.exe` 或 `Siming.apk`，并使用同一 Release 中的 SHA-256 文件校验完整性。
